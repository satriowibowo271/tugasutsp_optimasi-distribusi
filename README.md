# Tugas UTS & UAS - Analisis dan Optimasi Sistem Distribusi (Transportation Problem) - FULL

Project lengkap: Python (continuous, integer, fixed-cost), workbook Excel ready (.xlsx), dokumentasi, dan panduan GitHub.

## Cara menjalankan (Python)
1. Pastikan Python 3.8+ terpasang.
2. Install dependencies:
   pip install -r requirements.txt
3. Contoh menjalankan:
   cd src
   python optimize_transportation.py
   python optimize_transportation_integer.py
   python optimize_transportation_fixedcost.py

## Excel
Buka file excel/excel_solver_ready.xlsx dan jalankan Solver seperti dijelaskan di docs/excel_solver_instructions.md

## Upload ke GitHub
1. Buat repo baru di GitHub (empty).
2. Jalankan di terminal:
   git init
   git add .
   git commit -m 'Initial commit - full Tugas UTS project'
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO_NAME.git
   git push -u origin main
